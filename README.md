# Data Analysis Course (CSCI322)

This repository contains lab assignments and projects for the Data Analysis course (CSCI322). The labs cover various topics in data analysis, visualization, and machine learning using Python.

## 📚 Course Content

### Lab 01 - Introduction to Data Analysis
- Introduction to data manipulation and analysis
- Working with the heart disease dataset
- Basic data preprocessing and exploration

### Lab 02 - Data Processing
- Customer data analysis
- Data cleaning and transformation techniques

### Lab 03 - Advanced Data Processing
- Further exploration of data processing techniques

### Lab 04 - TED Talks Analysis
- Analysis of TED talks dataset
- Feature exploration and insights extraction

### Lab 05 - Data Visualization
- Comprehensive data visualization techniques
- Working with multiple datasets (diamonds, fuel economy, pokemon)
- Creating meaningful visualizations using matplotlib and seaborn

### Lab 06 - Advanced Topics
- Advanced data analysis techniques

### Lab 07 - Linear Regression
- Introduction to linear regression
- Model building and evaluation
- Prediction and analysis

### Lab 08 - Clustering
#### Lab 09 - K-means Clustering
- K-means algorithm implementation
- Cluster analysis and evaluation

#### Lab 10 - Hierarchical Clustering
- Hierarchical clustering techniques
- Dendrogram visualization
- Cluster interpretation

## 🛠️ Prerequisites

- Python 3.x
- Jupyter Notebook
- Required Python libraries:
  - pandas
  - numpy
  - matplotlib
  - seaborn
  - scikit-learn

## 🚀 Getting Started

1. Clone this repository:
```bash
git clone <repository-url>
cd Data-Analysis-Course
```

2. Set up a virtual environment (optional but recommended):
```bash
python -m venv venv
venv\Scripts\activate  # On Windows
```

3. Install required packages:
```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

4. Launch Jupyter Notebook:
```bash
jupyter notebook
```

5. Navigate to the desired lab folder and open the notebook
